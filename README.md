# 🎓 Student Performance Prediction System

A Machine Learning-based web application that predicts student exam performance based on various academic, personal, and socioeconomic factors. Built with **Python**, **scikit-learn**, and **Streamlit**.

---

## 📌 Project Overview
This project leverages machine learning to help educators and students understand the key drivers behind academic performance and predict final exam scores based on customizable input features.

### Key Features:
- **Interactive UI**: User-friendly form built using Streamlit.
- **Machine Learning Model**: Trained model pipeline using scikit-learn.
- **Real-time Prediction**: Instant score estimation based on user inputs.

---

## 🛠️ Tech Stack
- **Language**: Python 3.x
- **Machine Learning**: Scikit-Learn, Pandas, NumPy, Joblib
- **Frontend / Web Framework**: Streamlit
- **Development Environment**: Jupyter Notebook / JupyterLab
