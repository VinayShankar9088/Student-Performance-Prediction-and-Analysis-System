# Student Performance Prediction — Jupyter Project

## Files
- `Student_Performance_Prediction.ipynb`: main notebook
- `StudentPerformanceFactors.csv`: dataset

## Run
1. Install Python and Jupyter, or open the notebook in Anaconda Navigator.
2. If required, install libraries in a notebook cell:
   `!pip install pandas numpy matplotlib seaborn scikit-learn`
3. Open `Student_Performance_Prediction.ipynb`.
4. Run cells from top to bottom.
5. Review the printed MAE, RMSE, R², charts, and feature importance before writing your conclusion.

The project predicts `Exam_Score`. It is an educational demonstration, not a causal analysis.
